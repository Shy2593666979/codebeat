# 隐私说明

codebeat 非 OpenAI / Anthropic 官方产品。应用不提供云端存储或遥测。

任务提示词、会话 ID、项目目录、设置与运行摘要存储于 `%LOCALAPPDATA%\codebeat`。目录 ACL 限制为当前 Windows 用户访问；当前版本未使用 DPAPI，拥有当前用户权限的进程仍可能读取数据库。不要将密码、密钥放入提示词。

登录凭据由官方 CLI 管理。本应用不读取浏览器 Cookie、登录凭据文件，不保存 API key。查询额度与执行任务会通过官方 CLI 访问相应厂商服务，适用各厂商政策和订阅限制。

Claude 会话检索仅以只读方式扫描当前用户 `.claude/projects` 的有限深度 JSONL 元数据。损坏文件会跳过或给出警告，不修改原始会话。

默认不保存模型完整输出。用户启用后本地日志可能包含项目代码；常见 Bearer / sk- 密钥会遮挡，但不能保证发现所有形式的敏感信息。日志单文件 10 MB，最多 5 份轮转，维护任务清理 14 天前日志；额度快照保留 30 天。卸载默认保留本地数据，确认不再需要后可手动删除此应用的数据目录。
