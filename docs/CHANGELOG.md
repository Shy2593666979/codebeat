# 0.1.0 — 工程预览版

- 界面统一使用“提供商”；通知按对象与事件类型原位更新，开关状态不再反复堆叠。增加默认关闭的 `notification-demo` 打包特性，本次预览包携带两条内存演示通知，查看/忽略约 15 秒后补回，后续普通打包可直接移除。

- 托盘菜单调整字号、间距与阴影，供应商浮层左对齐；消息改为带类型图标、时间及数量的紧凑卡片，列表使用独立窄浮层。新消息提醒按 500ms 显示、500ms 隐身循环；列表使用气泡标题、两行正文省略、无内部滚动和尖角，中心贴近托盘图标，全部消息随窗口高度展开。

- 增强设置中的工作时间优化（不新增页面）：午休默认关闭，支持跨午夜、临时日程、三种模式、候选评分、官方窗口动态重排和紧凑时间线，更多选项在设置卡片内展开。增加持久化请求防重、执行前复查、消耗异常暂停、独立一次性唤醒与 ChatGPT 桌面兼容提示。详见 [AWO](docs/FEATURES.md#智能工作时间优化awo)。本次仅验证源码，不打包。

- 托盘左键打开主界面，右键显示菜单；运行状态浮层按悬停展开，菜单与浮层随显示器等比例适配并动态对齐箭头。移除额度更新时间旁的圆圈提示图标。
- 新建任务的会话气泡图标统一增加三个点。

- 工具连接检测间隔调整为 5/10/30/60 分钟，默认 10 分钟，前后端校验和英文文案同步；旧 15 分钟配置读取或导入时兼容为 10 分钟。

- 按确认方案合并 Rust 共享模块为 codebeat-lib，保留独立 codebeat-runner；桌面入口拆分 commands/notifications/tray/window，前端归入 services/stores/composables/types，同步测试、Windows CI 与打包路径。详见 [当前项目结构](docs/ARCHITECTURE.md#项目结构)。

- 主窗口按显示器工作区与 DPI 整体等比适配，提供立即生效的每屏缩放偏好及正常窗口大小记忆。
- 新增持久化托盘消息提醒：待查看时图标持续闪动，悬停查看列表、点击跳转、底部忽略全部；主界面完整展示后确认并延续两秒进度条关闭。详见 [说明](docs/FEATURES.md#屏幕适配与托盘消息)。

- 按新创建任务参考图重做创建/编辑弹窗：左侧工具与会话卡片、右侧任务表单、固定确认按钮；删除预览步骤，直接确认创建或修改，保留权限、周期、唤醒及通知配置。侧边栏会话气泡增加三个实心圆点。

- 提供方图标内部 SVG 图片按所在外框比例缩放，移除历史固定像素尺寸，修复设置卡片及预启动小按钮中 Codex / Claude Code 图标被裁切的问题。

- 移除设置页“更多设置”入口及“更改自动生效”常驻文字；自动保存保留，卡片间距、内边距和行距放宽，默认窗口继续一页显示。

- 设置改为自动应用，移除底部保存/取消栏和设置成功弹窗；常用设置在默认窗口中一页呈现，预启动记录默认折叠。连续更改合并提交、请求按序执行，失败显示页面内重试。

- 新增按作息预启动额度窗口：工作日 / 每天、工作时间及午休、工具选择、推荐计划、独立后台检查、请求结果与官方窗口确认。默认关闭。详见 [使用说明](docs/FEATURES.md#按作息预启动额度窗口)。

- 内置基于 Noto Sans SC 的 CodeBeat UI 字体，固定四个真实字重，统一主界面及原生通知；增加实际绘制字体与通知字体文件检查。

- 按新增消息图实现屏幕右上角独立通知卡片，支持任务/额度跳转、关闭、自动收起、声音和多条消息排队；任务状态文案改为中文。

- 额度卡片以五小时 / 一周等可读时长展示窗口；百分比及进度条统一显示剩余额度，未知数据保持未知。

- Vue 3 五页工作空间、四套配色、深色模式与基本中英文导航。
- Rust 领域校验、SQLite WAL 迁移、原子执行抢占、独立 Runner。
- Codex JSON-RPC 官方额度 / 会话、Claude 本地会话与受限续聊参数。
- Windows Task Scheduler COM 任务注册、错过策略、日志与结果记录。
- Windows CI、NSIS / WebView2 配置、SHA-256 输出。

不宣称正式版本验收完成。预启动真实五小时周期、睡眠与干净 Win10/11 安装须按验收文档实测。

- 开关悬停保持轨道颜色与位置稳定，点击才切换状态，保留键盘操作和焦点提示。

- 会话记录移除状态筛选标签和常驻详情栏，右键菜单提供创建定时任务、立即继续及会话详情；详情改为按需读取的弹窗，支持菜单键盘操作与窗口边缘定位。
